# v0

A v0 app is usually Next.js
([../classes/nextjs.md](../classes/nextjs.md)), with React server components
and route handlers.

- `NEXT_PUBLIC_*` values are build variables. Other values are runtime
  settings or secrets.
- The AI SDK (`ai`, `@ai-sdk/openai`, `@ai-sdk/anthropic`): attach the AI
  add-on ([../addons.md](../addons.md)). It gives `OPENAI_API_KEY`,
  `OPENAI_BASE_URL` and the Anthropic pair, which the providers of the AI SDK
  read. Remove a key or a base URL from the code. Do not ask the person for a
  provider key.
- A server call to another outside API needs the host allowed
  ([../outbound.md](../outbound.md)).
- Vercel-only features do nothing on Apervia: `vercel.json`, Vercel KV, Blob
  and Postgres, Edge Config, cron jobs in `vercel.json`. Replace a store with
  an add-on ([../addons.md](../addons.md)), and tell the person about the rest.
  `@vercel/analytics` does no harm, but it collects nothing.
- `export const runtime = "edge"` still runs, as a Node.js server.
